# 모듈 CLAUDE.md 스키마 (≤50줄)

`gotcha` 스킬이 모듈 지식을 기록할 때 이 골격을 쓴다. **파일을 미리 만들지 않는다** — 기록할 항목이 생긴 모듈에만 생긴다.

## 규칙

- 역할 · 공개 API · 의존성 섹션을 쓰지 않는다. 셋 다 코드 요약이다.
- 항목이 0개면 파일을 만들지 않는다. 파일이 존재한다는 것은 이 모듈에 알아야 할 것이 있다는 뜻이다.
- 한 항목은 한 줄이며 `{내용} — {이유}` 형식이다.

## 출력 골격

```markdown
# {모듈명}

## 하지 마라
- {금지} — {이유}

## 암묵 규칙
- {규칙} — {이유}
```
