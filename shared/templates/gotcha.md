# GOTCHA 템플릿

`harness-init` 인터뷰와 `gotcha` 스킬이 이 골격에 맞춰 `docs/GOTCHA.md` 를 쓴다.

## 규칙

- 한 항목은 한 줄이며 `{내용} — {이유}` 형식이다.
- 이유를 반드시 쓴다. 이유가 없으면 나중에 이 항목을 지울 판단을 할 수 없다.
- 섹션이 비면 그 섹션 헤더를 쓰지 않는다. 항목이 0개면 `# GOTCHA` 1줄만 남는다.
- 코드를 읽으면 나오는 내용을 쓰지 않는다.
- 상한은 60줄이다. 50줄을 넘으면 모듈로 내릴 항목을 제안하고, 60줄에서는 새 항목 추가 전에 기존 항목 하나를 내리거나 지운다.

## 출력 골격

```markdown
<!-- ≤60줄. 자동 적재 — 코드로 알 수 있는 것은 쓰지 않는다. -->
# GOTCHA

## 과도기 — 어느 쪽이 목적지인가
- {A} → {B} 이전 중. 신규는 {B} — {근거}

## 죽은 것 — 있지만 쓰지 마라
- {심볼/모듈} — {상태와 이유}

## 하지 마라
- {금지} — {이유}

## 팀 규칙 — 코드 밖에 있는 것
- {규칙} — {이유}
```
