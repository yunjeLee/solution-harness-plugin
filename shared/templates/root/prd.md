# prd 모듈

호출자 (`/harness-root`, `/harness-root-edit`) 가 Read tool 로 읽고 지침을 따른다. 사전 스캔 결과로 자동 초안을 생성하고 신뢰도 태깅한다.

## 대상 파일

`docs/rules/PRD.md`

## 사전 스캔

질문 시작 전 아래 소스를 Read / Glob / Bash 로 확인한다.

| 소스 | 용도 |
|------|------|
| `README.md` 상단 1~2 문장 | 앱 설명, 외부 문서 링크 |
| `settings.gradle.kts` / `Package.swift` | 모듈 / 타겟명 (앱 영역 추론) |
| 패키지 루트 디렉토리 이름 | 도메인 추론 (`booking`, `payment`, `chat` 등) |
| `git tag --list` + `git log --oneline | wc -l` | 출시 단계 추정 |

### 결과 형식

- 앱 한 줄 요약 (README + 패키지명)
- 사용자 / 사용 맥락 키워드 추론
- 출시 단계 추정 (MVP / Growth / Mature)
- 외부 문서 링크 후보

## 신뢰도 판정 규칙

| 섹션 | 스캔 소스 | 판정 |
|------|----------|------|
| 이 앱이 하는 일 | README 1~2 문장 + 패키지명 | README 존재 → `[추정]`, 없음 → `{TBD: README 없음}` |
| 주요 사용자 & 사용 맥락 | feature 모듈명, domain 키워드 | 모듈명에서 추론 가능 → `[추정]`, 불가 → `[검수 필요]` |
| 핵심 가치 | README 에 명시된 경우만 | 명시 → `[확정]`, 없음 → `[검수 필요]` |
| 출시 상태 | git tag + commit 수 | tag/commit 기반 → `[추정]` |
| 외부 상세 문서 | README 내 http(s) 링크 | 링크 존재 → `[확정]`, 없음 → `{TBD: README 내 링크 없음}` |

## 초안 생성 로직

Phase 1 사전 스캔 결과를 바탕으로 각 섹션의 초안 텍스트와 신뢰도 태그를 자동 생성한다. 사용자에게 묻지 않는다.

- README 가 없거나 비어있는 경우: 패키지명 + 모듈명에서 최대한 추론하되, 추론 불가 시 `{TBD: 패키지명/모듈명에서 추론 불가}`.
- 출시 상태: tag 없음 + 커밋 < 50 → MVP, tag 있음 + 활발 → Growth, tag 있음 + 활발 X → Mature.
- 외부 문서: README 내 http(s) 링크를 자동 수집. 없으면 `{TBD: README 내 링크 없음}`.

````markdown
{초안 텍스트 또는 {TBD: README 내 링크 없음}}
````
