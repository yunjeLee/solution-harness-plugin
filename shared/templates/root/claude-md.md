# CLAUDE.md 템플릿

`harness-init` 이 이 골격으로 루트 `CLAUDE.md` 를 만든다. 상한 40줄.

## 구성

| 블록 | 만드는 주체 | 재실행 시 |
|---|---|---|
| `## 자동 적재` | 고정 1줄 | 덮어쓴다 |
| `## CRITICAL` | 인터뷰 (상 등급 답변 중 전역 금지만) | **덮어쓰지 않는다. 추가만 한다** |
| `## 조건부 로딩` | `shared/scripts/index-modules.mjs` | 덮어쓴다 |

## 규칙

- 자동 적재 대상은 `docs/GOTCHA.md` 하나다. 문서별 H2 헤더를 두지 않는다.
- 조건부 로딩 줄을 손으로 쓰지 않는다. 스크립트 출력을 그대로 넣는다.
- 모듈 접근 줄을 만들지 않는다. 모듈 `CLAUDE.md` 는 **파일 위치 자체가 트리거다.** (2026-09-02 사용자가 직접 확인. 등록 줄 41개를 만들 필요가 없다.)
- 응답 스타일·언어 지침을 쓰지 않는다. 개인 `~/.claude/CLAUDE.md` 소관이다.

## 출력 골격

```markdown
<!-- ≤40줄 -->
# 프로젝트: {이름}

## 자동 적재
@docs/GOTCHA.md

## CRITICAL
- {전역 금지} — {이유}

## 조건부 로딩
{index-modules.mjs 출력}
```
