# 인터뷰 절차 — 사람 지식 수집

`harness-init` 이 Read 해 실행한다. **스킬이 아니다. 외부에서 직접 호출하지 않는다.**

에이전트는 사람에게 물을 수 없다. 질문은 메인 컨텍스트가 한다.

## 3층

| 층 | 하는 일 |
|---|---|
| `shared/scripts/signals.mjs` | 이상 신호 7종을 결정론적으로 수집 |
| `harness-scout` (mode=interview) | 신호 주변 코드 확인 → 등급·순위 → 질문 문안 작성 |
| 메인 | 질문하고 답을 받아 **즉시 파일에 기록** |

## 이상 신호 8종

| `kind` | 뜻 | 층 |
|---|---|---|
| `unused` | 선언됐는데 참조 0건 | 스크립트 |
| `deprecated` | `@Deprecated` 인데 사용 중 | 스크립트 |
| `hack` | `HACK` · `FIXME` · `TODO` 주석 | 스크립트 |
| `reversed` | 의존 방향 역전 | 스크립트 |
| `orphan` | 진입차수 0 모듈 | 스크립트 |
| `untested` | 테스트 소스셋 없는 모듈 | 스크립트 |
| `moved` | 최근 대량 이동·삭제 | 스크립트 |
| **같은 역할이 둘** | 같은 일을 하는 모듈·라이브러리 2개 | **에이전트** |

## 등급

| 등급 | 기준 |
|---|---|
| 상 | 모르면 모델이 틀린 코드를 쓴다 |
| 중 | 모르면 모델이 불필요한 일을 한다 |
| 하 | 알면 좋지만 없어도 동작한다 |

순위 = 모델 오판 위험 × 영향 범위(참조 수) × 최근 변경. 등급 순으로 배치한다.

## 묶기

같은 `kind` 가 여러 건이면 질문 1개로 접는다. 예: `untested` 32건 → "테스트가 없는 모듈이 32개다. 의도한 것인가?" 1문항.

## 진행

1. 한 라운드는 **8문항**이다. 총량 상한을 두지 않는다.
2. 진행률은 라운드 안에서만 표시한다(`3/8`). 전체 총량을 표시하지 않는다.
3. 라운드가 끝나면 계속 여부를 묻는다.
4. **등급이 바뀌는 지점**(상→중, 중→하)에서 중단 가능함을 명시하고 **기본값을 중단(`N`)** 으로 둔다.
5. 신호가 소진되면 자동 종료한다.

## 질문 규칙

- 앵커(파일 · 심볼 · 경로)를 질문문에 넣는다. 열린 질문을 쓰지 않는다.
- 객관식을 기본으로 한다.
- 모든 질문에 **"모름"** 선택지를 둔다.
- **질문 1개가 GOTCHA 1줄을 단독으로 완결시킨다.** 이유를 같은 질문에서 함께 받는다. 두 질문을 합쳐야 한 줄이 되는 구조를 만들지 않는다.
- 답변 직후 **즉시 파일에 기록한다.** 인터뷰 종료를 기다리지 않는다.
- "모름"이면 그 항목을 쓰지 않는다.

### 좋은 질문 / 나쁜 질문

| | 예 |
|---|---|
| 나쁨 | "이 프로젝트의 암묵 규칙이 있나요?" — 사람이 백지가 된다 |
| 좋음 | "`{모듈}.{인터페이스}` 가 선언돼 있는데 참조가 0건입니다. ① 폐기 예정 ② 마이그레이션 중 ③ 의도된 확장점 ④ 모름" |

좋은 예의 앵커는 **그 레포에서 스크립트가 실제로 찾아낸 신호**로 채운다. 특정 프로젝트의 심볼을 이 문서에 적지 않는다 — Global Constraints 가 금지하고, 그 심볼이 사라지면 예시가 먼저 썩는다.

## 기록

`.harness/interview-log.json` 에 남긴다.

```json
[
  { "id": "unused:{파일}#{앵커}", "answered": "폐기 예정" },
  { "id": "untested:{파일}#{앵커}", "answered": "모름" }
]
```

- 신호 식별자는 `{kind}:{파일}#{앵커}` 다. **행 번호를 쓰지 않는다.**
- "모름"도 답한 것으로 본다. **다시 묻지 않는다.**
- 다음 실행은 이 목록에 있는 `id` 를 제외하고 수집한다.

## 답변 배치

| 조건 | 위치 |
|---|---|
| 이 지식을 알아야 하는 파일들이 한 모듈 안에 있다 | `{module}/CLAUDE.md` |
| 여러 모듈에 걸친다 | `docs/GOTCHA.md` |
| 전역 금지이며 등급이 상 | `CLAUDE.md` 의 `## CRITICAL` |

동점이면 모듈이 기본값이다. 모듈 파일이 없으면 그때 만든다.
